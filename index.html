How to Install & Run

  1. Tap the "Download Delta" button above.
  2. Tap Install on the iOS system prompt.
  3. Return to home screen and wait for download to finish.
  4. Navigate to Settings > General > VPN & Device Management.
  5. Select the enterprise certificate and tap "Trust".
  1. Install KSign using the dedicated section above.
  2. Tap "Download Delta iPA" to save the `.ipa` file to your iOS Files app.
  3. Open KSign and import the downloaded Delta iPA file.
  4. Sign the application with your active certificate and select Install.
